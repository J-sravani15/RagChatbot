# Changelog

All notable changes to StudentAI are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-20

### Added

- Initial release of StudentAI.
- PDF upload and text extraction using PyMuPDF4LLM.
- Section-based document chunking with keyword retrieval.
- Local LLM inference using llama.cpp with TinyLlama model.
- Streamlit-based web interface with chat functionality.
- Typewriter effect for response rendering.
- Retrieved context display in expandable sections.
- Clean chat functionality.
- Pre-commit configuration with Ruff, Mypy, and Pytest.
- Unit tests for section building logic.
- Comprehensive documentation (README, CONTRIBUTING, USER_MANUAL, etc.).
- Quality tooling: Bandit, Pylint, Semgrep, Pyupgrade, Vulture, Radon.
- Docker support for containerized deployment.
- EditorConfig for consistent coding styles.
- Contributor guidelines and code of conduct.
- Security policy and issue reporting guidelines.
