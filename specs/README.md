# Feature Specifications

This directory contains feature specs for StudentAI.

## Structure

- `specs/rag/` — Retrieval-Augmented Generation specs
- `specs/ui/` — User interface specs
- `specs/security/` — Security and compliance specs

## Creating a New Spec

1. Choose the appropriate template from `.specify/templates/`
2. Copy it to the relevant subdirectory
3. Fill in all sections
4. Submit for review
